# 🎨 Vibe Gallery

Ek alag type ki gallery app (Kotlin + Jetpack Compose). Photos date ya folder se nahi, **rang/mood (vibe)** se organize hoti hain.

- 🎨 Har photo ka dominant color Palette API se nikalta hai aur use Fire / Sunset / Ocean / Night jaise vibes me baant deta hai
- 🏷️ Vibe chips se filter karo
- 🎲 "Surprise me" - random vibe photo
- 🌈 Viewer ka background photo ke rang ke hisaab se badalta hai (ambient glow)
- 🔍 Double-tap se zoom, swipe se next photo

Android Studio me kholo, Sync karo, Run karo. (minSdk 29)
